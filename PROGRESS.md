# Bounty Board Progress

Campus micro-task marketplace for Indian university students.

## Milestones

- [x] **M0: Foundation (v0.1)** - Repo setup, Python 3.13 + Django 5.2 layout, split settings, CI, env config, PROGRESS.md.
- [x] **M1: Design System (v0.2)** - Neo-brutalist CSS architecture, base layout, /styleguide/, custom error handlers (400, 403, 404, 500).
- [x] **M2: Accounts (v0.3)** - User registration with unique email, optional domain restriction, auth flows, /me/, Moderators group migration.
- [x] **M3: Bounties (v0.4)** - Bounty domain model, clean validation, admin, board filtering/search/pagination, seed_demo command, tests.
- [x] **M4: Claims & Permissions (v0.5)** - Atomic claim acceptance (select_for_update), contact visibility rules, withdrawal, notification emails, race tests.
- [x] **M5: Sessions & Cookies (v0.6)** - Recently viewed strip (session), bb_layout cookie toggle (grid/list), /me/ dashboard, tests.
- [ ] **M6: Trust & Hardening (v0.9)** - Abuse reports, moderation, rate limiting, production security, health check, sitemap, 35+ test suite, Procfile.
- [ ] **M7: Release (v1.0.0)** - Comprehensive README, syllabus map, screenshots, CHANGELOG, v1.0.0 git tag.
