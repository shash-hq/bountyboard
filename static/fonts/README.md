# Self-hosted fonts

| File | Family | Subset | Source |
| :--- | :--- | :--- | :--- |
| `archivo-latin.woff2` | Archivo (variable, weights 400-700) | Latin | Google Fonts, `fonts.gstatic.com/s/archivo/v25/` |
| `bricolage-latin.woff2` | Bricolage Grotesque (variable, weights 700-800) | Latin | Google Fonts, `fonts.gstatic.com/s/bricolagegrotesque/v9/` |

Both families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org/). They were copied unmodified, so redistribution is allowed;
keep this file with them. Only the Latin subset is included; add the `latin-ext`
files from the same Google Fonts stylesheet if non-English names need to render.
